# ✨Global CO2 Dashboard with Tableau✨

I made a dashboard showing the global CO2 emissions using Tableau. Inside, I showed a map of CO2 emissions by country. I also made a scatterplot of CO2 emissions in 2021 vs. population by country and a line chart of CO2 emissions global share per country and per year. 

The Tableau file itself can be accessed in the "_CO2 Dashboard.twbx_" file and by accessing the following URL (https://public.tableau.com/views/CO2Dashboard_17461585398750/GlobalCO2Emission). Also, the data I used can be accessed in the file _visualizing_global_co2_data.csv_. 
For further information about that data and the fields, open the file _visualizing_global_CO2_emissions_data_dictionary.xlsx_.
